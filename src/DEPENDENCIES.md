# 部品どうしのつながり

`python3 tools/deps.py` で自動生成（`build.py` を実行すると更新される）。手で書き換えない。

部品は番号順に1つのモジュールとしてつながる。後ろの部品で作る名前は、前の部品の「読み込み時に動く処理」からは使えない（関数の中や毎フレームの処理からは使える）。
